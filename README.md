# Bongo Waifu — Unlocked Clothes

## What it does

Browse every Bongo Waifu outfit, preview clothing combinations on the animated game model, and apply the selected look to your local game.

## How to use

1. Open the [latest release](https://github.com/BongoWaifuMods/bongo-waifu-unlocked-clothes/releases/latest) and download `BongoWaifu-Unlocked-Clothes-Setup.exe`.
2. Run the installer and open **Bongo Waifu — Unlocked Clothes**.
3. Close Bongo Waifu before changing a look.
4. Choose the body, hair, clothes, and accessories you want.
5. Select **Apply**, then open the game.
6. To undo the changes, open **Options** and select **Restore**.

## How it works

The tool finds the Steam installation, reads the local wardrobe assets, and uses the game's model and animations for the preview. When you apply a look, it creates a backup and updates only the selected visual data on your computer.
